# Hello-ai-GIS

> 用 AI 写出的轻量 GIS 工具，让高中生也能像地理学家一样解构真实世界。

## 项目愿景

专业 GIS 软件（ArcGIS、QGIS 等）功能强大，但对普通高中生来说门槛过高：安装复杂、界面英文、操作繁琐。本项目借助 AI 生成 HTML 的能力，把专业 GIS 软件中的核心功能**简化、轻量化**，以**纯网页（HTML）**的形式部署——学生打开浏览器就能用，无需安装任何东西。

高中生可以借助这些轻型 GIS 工具，亲手解构真实的地理学案例：**看空间分布、叠图层、测距离、析成因**，用更符合这个时代的方式学习高中地理。

## 目标用户

- **主要**：中国大陆高中地理教师（备课、课堂演示、布置探究任务）
- **次要**：高中生（课堂探究、研学实践、地理竞赛备赛）

## 核心原则

1. **零安装**：双击打开 HTML 文件，或访问一个网址即可使用
2. **低门槛**：界面中文、操作三步以内、有引导提示
3. **案例驱动**：每个工具都配套一个真实地理案例，不做"为技术而技术"的演示
4. **紧扣课标**：功能设计对齐高中地理课程标准（人教版/中图版/湘教版等）
5. **开源免费**：所有工具与案例素材均开源，教师可自由用于教学

## 拟开发的轻量 GIS 工具（路线图）

### 第一阶段：地图基础（先跑通最小闭环）
- [ ] **交互地图查看器**：缩放、平移、切换底图（矢量/影像/地形）
- [ ] **地理位置速查**：地名/坐标互查，认识经纬度与半球划分
- [ ] **距离与面积测量**：基于地图的量算，配合"地球形状与大小"教学

### 第二阶段：空间分析入门
- [ ] **图层叠加分析**：如"地形 + 气候 + 人口"多要素叠加，解构农业区位
- [ ] **缓冲区分析**：以某设施（学校、医院、工厂）为中心做服务范围分析
- [ ] **地形剖面图生成**：等高线 → 剖面线，理解地势起伏
- [ ] **热力图工具**：人口密度、PM2.5 等点数据的空间表达

### 第三阶段：遥感与综合案例
- [ ] **简易遥感影像解读**：对比不同波段/时相影像（如城市扩张、洪涝监测）
- [ ] **案例工坊**：成套的真实案例包——"从一片稻田看懂季风水田农业""从一张热力图读懂城市内部空间结构"
- [ ] **学生成果导出**：一键导出分析图，用于作业与报告

## 技术路线

| 层面 | 选型 |
| --- | --- |
| 载体 | 纯 HTML + JavaScript（单文件，便于分发） |
| 地图引擎 | Leaflet / MapLibre GL（开源、轻量） |
| 底图与数据 | OpenStreetMap、天地图、开放地理数据 |
| 生产方式 | 教师提出需求 → AI 生成代码 → 课堂实测 → 迭代修正 |
| 托管 | GitHub Pages（学生零门槛访问） |
