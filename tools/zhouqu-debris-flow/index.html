点击上方按钮，依次解构这场灾害的四个成因要素。

  1. 测一测：点地图左上角 📏，量一量三眼峪沟口到县城的距离，再算一算泥石流前锋的速度。
    2. 参考答案距离约 2 km；前锋用时 2.1 分钟 = 126 秒，速度 ≈ 2000÷126 ≈ 16 m/s ≈ 57 km/h——相当于高速公路上飞驰的汽车，且呈"墙"状整体推进。
  2. 比一比：同样约 2 km，三眼峪前锋用了 2.1 分钟，罗家峪却用了 4.3 分钟。可能是什么原因？
    3. 思路提示两条沟的宽窄、阻塞程度、物源补给量不同；三眼峪流域面积更大、汇流更集中。可对照地图上两条沟的形态差异讨论。
  3. 想一想：四个要素（陡峻地形、丰富松散物源、超强暴雨、人类侵占河道）若缺少一个，灾害还会发生吗？这说明什么？
    4. 思路提示泥石流是多因素叠加的结果。有地形和物源但无暴雨，可能只是潜在隐患；暴雨是"扳机"，但扳机之所以致命是因为枪膛里早已上膛。
  4. 议一议：舟曲县城建筑侵占了泥石流入江通道，给今天的城市规划什么启示？
    5. 思路提示尊重自然通道（行洪通道/沟谷）的规划红线；灾害风险评估应前置到选址阶段；人地协调。
