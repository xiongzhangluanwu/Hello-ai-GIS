# 案例档案：甘肃舟曲"8·8"特大山洪泥石流（2010）

> 本档案是 Hello-ai-GIS 项目的第一个教学案例，配套工具：`tools/zhouqu-debris-flow/`

## 一、事件要素

| 要素 | 内容 |
| --- | --- |
| 发生时间 | 2010 年 8 月 8 日 0 时 12 分 |
| 地点 | 甘肃省甘南藏族自治州舟曲县城北部，三眼峪、罗家峪两条泥石流沟 |
| 沟口距县城 | 约 2 km |
| 触发降水 | 8 月 7 日 23–24 时局地短时暴雨：1 小时雨量 96.77 mm，半小时瞬时 77.3 mm（县城同期仅中雨） |
| 伤亡 | 1467 人遇难，298 人失踪 |
| 冲出固体物质 | 合计 181 万 m³（三眼峪 150 万，罗家峪 31 万） |
| 运动速度 | 三眼峪前锋出山口至县城仅 2.1 分钟；罗家峪 4.3 分钟 |
| 目击者描述 | "像一堵高约 10 m 的墙，速度比高速火车还快" |
| 高程背景 | 县城约 1400 m，北侧山地最高 3828 m，相对高差超 2400 m |

## 二、灾害链时间线

- **8 月 7 日 14 时前后**：中尺度对流触发，云团向东南方向移动
- **8 月 7 日 23–24 时**：三眼峪、罗家峪流域突降超强暴雨（小时雨量 96.77 mm）
- **8 月 8 日 0 时 12 分**：两沟分别汇聚形成巨大山洪，铲刮沟内堆积物形成泥石流
- **0 时 12 分 + 2~4 分钟**：前锋冲至县城，月圆村、椿场村几乎全部被毁
- **随后**：泥石流冲入白龙江，淤填河道约 1 km，江水壅高回水淹没县城部分区域，县城交通、电力、通讯中断

## 三、成因四要素（教学设计核心框架）

1. **地形**：山高沟深，"V"形谷狭窄陡峻，汇流迅速，重力势能巨大
2. **物源**：历史崩塌滑坡堆积丰富（流域松散物储量 3414 万 m³，可转化为泥石流的达 62.5%）；历史地震震松山体；2010 年以来持续干旱使岩土开裂、雨水更易渗入
3. **降水**：短历时超强暴雨是直接触发因子；且降水空间分布极不均匀（山上暴雨、县城中雨），预报与防范难度大
4. **人类活动**：县城建筑侵占泥石流进入白龙江的通道；长期植被破坏加剧水土流失

> 三眼峪自 1823 年（清道光三年）以来已发生十多次重大山洪泥石流——**同一地点反复成灾**是重要历史教训。

## 四、教学点（对接高中地理课标）

- 自然灾害的成因（多要素叠加）、危害与防御
- 水循环与降水（强对流天气、中尺度系统）
- 地表形态的塑造（流水作用、V 形谷）
- 地理信息技术应用（遥感解译、DEM、GIS 叠加分析）
- 人地协调观（城市规划、灾害风险管理）
