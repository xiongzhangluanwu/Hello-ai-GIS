# 案例档案：2018 年北海道胆振东部地震诱发滑坡（日本）

> Hello-ai-GIS 第二个教学案例，配套工具：`tools/hokkaido-iburi-landslide/`
> 定位：与舟曲案例组成"暴雨型 vs 地震型"地质灾害对比教学单元

## 一、事件要素

| 要素 | 内容 |
| --- | --- |
| 发生时间 | 2018 年 9 月 6 日 03:07:59（日本时间，凌晨） |
| 震级 | Mw 6.6（USGS）/ Mj 6.7（日本气象厅）/ Ms 6.9（中国地震台网）——同一地震三套震级标度 |
| 震中 | 42.686°N，141.929°E，深度约 35 km（札幌市东南约 40 km 的山间） |
| 最大烈度 | 厚真町震度 7（北海道观测史上首次）；USGS MMI 8.5 |
| 人员伤亡 | 44 人遇难（其中富里连片滑坡 36 人），约 640 人受伤 |
| 滑坡规模 | 各机构编目 3307–10120 处不等；遥感解译 7059 处，影响约 466 km²，约 400 km² 丘陵区密集分布 |
| 特殊之处 | 明治时代以来日本规模最大的地震滑坡群；海拔 100–400 m 低丘陵区成灾（非高山） |
| 次生影响 | 苫东厚真发电厂停运→北海道约 295 万户全域停电近一周；新千岁机场关闭；札幌清田区大面积土壤液化 |

## 二、成因四要素（教学框架）

1. **地震动（扳机）**：震度 7、最大 1796 gal（追分站）；约 80% 以上滑坡分布于 PGA > 0.5g 区域
2. **前期降雨（放大器）**：9 月 4 日台风"飞燕"过境，土壤接近饱和，孔隙水压力高
3. **火山灰地质（内因）**：丘陵覆盖厚层火山碎屑物（樽前山等来源），多孔松散易液化；震动液化型浅层滑坡为主，多从山脊启动
4. **地形与形态（表现形式）**：低海拔丘陵（100–400 m）、"小影响区域大滑坡面积"、多滑源点、面积指数分布

## 三、与舟曲案例的对比教学点

| 对比维度 | 舟曲（2010） | 北海道胆振（2018） |
| --- | --- | --- |
| 触发因子 | 短时超强暴雨（1 h 96.77 mm） | 强地震动（震度 7） |
| 前期条件 | 干旱→岩土开裂 | 台风降雨→土壤饱和 |
| 物源 | 历史崩塌滑坡堆积 3414 万 m³ | 厚层火山灰/浮石 |
| 地形 | 高差 2400 m 深切 V 形谷 | 100–400 m 低丘陵 |
| 运动形态 | 高速泥石流（"墙"状前锋） | 数千处浅层滑坡+碎屑流 |
| 防灾启示 | 行洪通道管控 | 火山灰区易发性区划+液化对策 |

共同本质：**松散物质 + 坡 + 水**三者叠加，触发因子只是"扳机"。
